# KODra Law of Unicity — Formal Definition

---

## ENGLISH

### 1. Main Formula

```
∀x ∈ M,  x → 𝟎 → U(x) ∈ M
```

Compact form: `x ⭐ 𝟎 = U(x)`

---

### 2. Symbols and Meanings

| Symbol | Name | Meaning |
|--------|------|---------|
| **∀** | Universal quantifier | "For all" — any element in the domain |
| **x** | Input / Raw element | Any object: number, text, concept, state, vector. The multiplicity before the Portal |
| **∈** | Membership | x belongs to domain M |
| **M** | Primordial multiplicity | The set of all existent objects before transformation. Source domain |
| **→** | Transformation / passage | Transition from one state to another through the Portal |
| **𝟎** | Portal / Void / Zero | The transition operator ("creative zero"). Interface between multiplicity and unicity |
| **U(x)** | Unicity of x | The final emergent state uniquely associated with x |
| **U** | Unicity | The emergent state. **U is NOT the number 1** — it is the Unicity operator |

---

### 3. Three Steps

**Step 1 — Domain**
```
∀x ∈ M
```
x is any element of M. M is the space of all possible states (raw data, chaos, multiplicity).

**Step 2 — Passage**
```
x → 𝟎
```
x enters into interaction with the Portal 𝟎. The Portal acts as a transformation and interface.

**Step 3 — Emergence**
```
𝟎 → U(x)
```
The Portal produces U(x): the final, unique state proper to x — its Unicity.

---

### 4. Important Clarifications

- **U is not the number 1**: U = Unicity (emergent state). The "1" in 1_x would mean "final state", not the scalar 1. Using **U** avoids ambiguity.
- **U(x) is x-specific**: Each x has its own Unicity U(x). At massive scale: x₁ → U(x₁), x₂ → U(x₂), etc.
- **𝟎 is an operator**: 𝟎 is not the scalar 0. It is the Portal: transformation, fertile void, interface.

---

### 5. Computational Realization

```
x (input)  →  x · void_matrix  →  transition(·)  →  tanh(·)  →  U(x) (output)
     ↑                  ↑                  ↑
  Multiplicity    Passage through 𝟎    Emergence U
```

- **void_matrix**: Representation of 𝟎 (the Portal)
- **transition**: Emergence mechanism
- **tanh**: Bounds U(x) in [-1, 1] for stability

---

### 6. One-Sentence Summary

> **For all x in multiplicity M, x traverses the Portal 𝟎 and emerges as U(x) — its Unicity: the final, unique, traceable state.**
